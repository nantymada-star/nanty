# Captures d'écran

Ces captures sont produites par le test navigateur automatique (`npm run e2e`).
Les réponses du réseau (HDX, OpenStreetMap, OSRM) y sont **simulées pour le test** :
les prix, marchés et commerces visibles ici (ex. « Test Supermarket ») ne sont pas des données réelles.
Dans l'application, seules les données réelles des sources sont affichées.
